# Лабораторная работа 1 — Анализ данных

## Датасет
insurance.csv — Medical Cost Personal Dataset (Kaggle)

## Описание колонок
- age (int) — возраст застрахованного
- sex (object) — пол
- bmi (float) — индекс массы тела
- children (int) — число детей
- smoker (object) — курит ли застрахованный
- region (object) — регион проживания
- charges (float) — медицинские расходы

## Используемые библиотеки
- pandas — чтение и обработка данных
- matplotlib — визуализация

## Предобработка данных
- df.info() — проверка типов данных
- df.isnull().sum() — проверка пропусков (не найдено)
- df.describe() — статистика по числовым столбцам

## Визуализации
- Гистограмма распределения возраста
- Сравнение средних расходов курящих и некурящих
- Количество застрахованных по регионам
